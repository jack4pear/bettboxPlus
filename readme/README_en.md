# BettboxPlus

This is an independent Bettbox customization using the pinned MihomoPlus kernel.
See the [current project README](../README.md), [installation instructions](../docs/INSTALL.md), and [signing policy](../SIGNING-POLICY.md).
Windows builds are unsigned. This fork does not inherit upstream signing or certification claims.
